HOTSCHEM / LOCAL IMPORTER

Your files. Ready for Minecraft.

Select local Craftmatic .mcpack or Sponge .schem v2/v3 files and create a Minecraft add-on. Conversion runs entirely in this browser. No server, upload, account or internet connection is needed.

Joining someone else’s LAN world?

The host must install the generated add-on and activate HotSchem in that world. Installing it only on your joining client cannot enable placement. Once HotSchem 0.5 is active on the host, joining players can paste live import codes into the Planner without restarting. New .mcpack behavior packs still need host activation if opened directly in Minecraft.

    Live import · keep the world running

    HotSchem 0.5 must already be active on the host. Choose one model below. Copy a part, switch to Minecraft, and open Planner → Choose another schematic → Import → Paste import code. Submit each part. The completed build appears in the Planner; set its location and review before placing.

    Multiple parts require switching between the browser and Minecraft. For large builds, downloading the add-on and restarting the host may be easier. Imports add to the saved world library; no build is placed automatically.
    Install and build
    1. Download the add-on and open it with Minecraft on the host device.
    2. Activate HotSchem Placement in the world’s Behavior Packs, then restart Minecraft. Use a creative world with cheats for this prototype.
    3. Join the world and use the red HotSchem Planner to choose, preview and place your build.

    Each import replaces the HotSchem menu library. Include all files you want to keep; existing placed builds remain.

    Entities, source container contents, block entity data and secondary water layers are not imported. Craftmatic block states and trimmed tile offsets are preserved. Java block-state conversion is partial; unsupported Bedrock materials stop placement. Legacy .schematic, .litematic and modded blocks are not supported. Save this HTML file to use it offline again.
